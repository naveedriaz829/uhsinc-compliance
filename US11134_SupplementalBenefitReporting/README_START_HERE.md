# US11134 - Supplemental Benefit Reporting

1. Extract this ZIP to a local folder.
2. Open Visual Studio Code -> File -> Open Folder -> select `US11134_SupplementalBenefitReporting`.
3. Keep the file under `02_Original_SQL/` unchanged; treat it as a reference.
4. Add reviewed/approved code only under `03_Development/`.
5. Keep read-only DEV checks under `04_Validation/` and record results in `05_Notes/` (no PHI).
6. Download the '2026 PBP - Plan name listing 052825.xlsx' ADO attachment into `01_Requirements/`.
7. Download the CY2026 Part C Technical Specifications linked in ADO into `01_Requirements/`.
8. Do not run Shreya's original SQL directly: it includes DELETE, TRUNCATE, INSERT, and UPDATE statements.

This workspace does NOT include the 2026 PBP list, because it was shown in a screenshot but not uploaded.
